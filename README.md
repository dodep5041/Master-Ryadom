# Мастер рядом

Telegram-бот для оформления и управления заявками на ремонт и бытовые услуги.

## О проекте

«Мастер рядом» — демонстрационный проект Telegram-бота, который позволяет клиентам оформлять заявки на бытовые и ремонтные услуги, а администраторам — получать заявки, просматривать их и управлять статусами.

Проект разработан на Python с использованием aiogram и SQLAlchemy.

## Возможности

### Для клиентов

- Просмотр доступных услуг.
- Создание заявки через пошаговый диалог.
- Выбор типа услуги.
- Описание проблемы.
- Возможность приложить фотографию.
- Указание города и района.
- Ввод имени и контактного телефона.
- Подтверждение согласия на обработку персональных данных.
- Просмотр собственных заявок.
- Просмотр подробной информации о заявке.
- Получение уведомлений об изменении статуса.
- Отмена оформления заявки на разных этапах.

### Для администратора

- Доступ к административным командам по Telegram ID.
- Просмотр списка заявок.
- Просмотр подробностей отдельной заявки.
- Изменение статусов заявок.
- Автоматическое уведомление клиента об изменении статуса.

### Статусы заявок

- Новая.
- В работе.
- Выполнена.
- Отменена.

## Установка

### 1. Клонирование проекта

```bash
git clone <ссылка-на-репозиторий>
cd Master-Ryadom
```

### 2. Создание виртуального окружения

```bash
py -3.13 -m venv .venv
```

### 3. Установка зависимостей

Windows:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`.

Укажите:

```env
BOT_TOKEN=токен_telegram_бота
ADMIN_ID=telegram_id_администратора
```

Не публикуйте файл `.env` и не передавайте токен бота третьим лицам.

## Запуск

Windows:

```powershell
.\.venv\Scripts\python.exe bot.py
```

При первом запуске автоматически создаётся база данных SQLite и необходимые таблицы.

## Запуск тестов

```powershell
.\.venv\Scripts\python.exe -m pytest -v
```

## Безопасность

- Административные команды доступны только указанному администратору.
- Клиенты могут просматривать только собственные заявки.
- Клиент не может удалить чужую заявку.
- Для создания заявки требуется согласие на обработку персональных данных.
- Секретные настройки хранятся в `.env`.
- База данных и виртуальное окружение исключены из Git через `.gitignore`.

Перед коммерческим использованием необходимо подготовить и опубликовать соответствующую политику обработки персональных данных, а также проверить требования законодательства применимой юрисдикции.

## Тестирование

На текущем этапе разработки успешно пройдены 11 автоматических тестов, проверяющих основные операции с заявками, разграничение доступа и обязательность согласия на обработку данных.

Основной пользовательский сценарий также проверен вручную в Telegram.
